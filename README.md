# Data Science Fundamentals — Mini Project

**Purpose:** Demonstrate basic Python, data types, descriptive statistics, validation, and readable code for a Data Analyst internship task.

## Dataset
A small example list of daily sales values (in rupees): `1200, 1500, 900, 1800`.

## What it does
- Calculates count, total, mean, median, minimum, maximum, and range.
- Uses functions to keep the code reusable.
- Checks that the input list is not empty.
- Uses only Python's standard library.

## Run
1. Install Python 3 if it is not already installed.
2. Download or clone this repository.
3. Run `python main.py`.

## Expected key results
- Count: 4
- Total: 5400
- Mean: 1350.0
- Median: 1350.0
- Minimum: 900
- Maximum: 1800
- Range: 900

## Limitations
This is an illustrative dataset, not real business data. It describes values but cannot explain the causes of sales changes. No personal or confidential data is included.
